#### 1. Part A: Context Length ($T=64 \dots 512$) & Out-of-Domain Generality
**File:** [`experiments/benchmark_length_and_domain.py`](file:///d:/CUDA-Graph/kv_continuity/experiments/benchmark_length_and_domain.py)
* **Solves the weakness:** Replaces the toy $N=6, T=64$ setup with authentic evaluation across:
  * **Sequence lengths:** $T \in \{64, 128, 256, 512\}$ tokens.
  * **Domains:** Standard natural language (**WikiText-2** validation split) and high-entropy, syntax-strict technical text (**Python Code / Algorithms**).
  * **Sample size:** $N = 25 \dots 50$ sequences per setting (thousands of evaluated tokens).
* **Conditions evaluated per setting:** Oracle Baseline (36L), Native Projection, and Direct Copy.
* **Metrics:** Perplexity, $\Delta\text{PPL}$, forward KL divergence ($\kl$ in nats), Top-1 agreement (%), and runtime latency ($\text{ms/tok}$).
* **Outputs:** 
  * `results/canonical_sweeps/qwen2.5_3b/length_and_domain_sweep.csv`
  * `results/canonical_sweeps/qwen2.5_3b/paper_table_length_and_domain.md`

#### 2. Part B: Multi-Depth Adapter Readout Characterization
**File:** [`experiments/sweep_adapter_depths.py`](file:///d:/CUDA-Graph/kv_continuity/experiments/sweep_adapter_depths.py)
* **Solves the weakness:** Addresses the critique that an adapter was only tested at 50% depth ($L=18$).
* **Candidate exit depths:** $L \in \{18, 22, 24, 28, 32\}$ (50.0%, 61.1%, 66.7%, 77.8%, 88.9% relative depth).
* **Protocol:**
  1. Base model is 100% frozen.
  2. Evaluates **Zero-Shot Intermediate Readout** (uncalibrated baseline).
  3. Trains a 2-layer MLP bottleneck adapter ($r=512$, ~2.1M params) via distillation ($50\% \text{ CE} + 50\% \text{ KD}, \tau=2.0$) on genuine WikiText-2 training split.
  4. Evaluates on disjoint validation sequences: Val PPL, $\kl$, Top-1 agreement, and empirical Top-1 recovery gain.
* **Outputs:**
  * `results/canonical_sweeps/qwen2.5_3b/multi_depth_adapter_sweep.csv`
  * `results/canonical_sweeps/qwen2.5_3b/paper_table_multi_depth_adapters.md`
  * Trained adapter weights: `checkpoints/multi_depth_adapters_qwen.pt`
