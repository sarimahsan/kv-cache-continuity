MODEL EVALUATION METRICS (USED IN PAPER & EXPERIMENTS)
======================================================

1. Perplexity (PPL)
   - Evaluates next-token language modeling quality under teacher forcing.

2. Delta Perplexity (ΔPPL)
   - Absolute perplexity increase relative to the full-depth oracle baseline (PPL_condition - PPL_oracle).

3. Mean Forward KL Divergence (D̄_KL)
   - Token-averaged forward KL divergence from oracle to approximate next-token probability distributions (in nats).

4. 1-Bit Operating Threshold (ln 2)
   - Acceptance criterion: D̄_KL <= ln(2) ≈ 0.6931 nats.

5. Top-1 Agreement Rate (%)
   - Percentage of sequence positions where the predicted argmax token exactly matches the oracle argmax token.

6. Key Cosine Similarity (cos_K)
   - Layer-wise cosine similarity between projected Key cache states (K̂) and true oracle Key states (K*).

7. Value Cosine Similarity (cos_V)
   - Layer-wise cosine similarity between projected Value cache states (V̂) and true oracle Value states (V*).

8. Relative Frobenius Norm Error (RelErr)
   - Relative norm error between oracle and projected Key/Value tensors: ||X* - X̂||_F / ||X*||_F.

9. Draft Token Acceptance Rate (α)
   - Fraction of speculative draft tokens accepted by the terminal verifier during speculative decoding.

10. Exact-Match Output Equivalence Rate (EM %)
    - Percentage of generated sequences that are 100% token-for-token identical to standard autoregressive generation.
